🚗 Previsão de Preços de Veículos – Base FIPE Janeiro/2026
Olá, mais um projeto! Um projeto de Machine Learning para estimativa de preços de veículos usando a base FIPE de janeiro de 2026, para os modelos a partir do ano de 2000. O objetivo foi analisar padrões, entender fatores determinantes e construir modelos preditivos robustos.
✨ Marcas analisadas:
Audi, BYD, GM, Citroën, Fiat, Ford, Honda, Hyundai, IVECO, JAC, Jeep, Kia, Mercedes-Benz, Mitsubishi, Nissan, Peugeot, Renault, Toyota, Volkswagen, Troller e Volvo.
💻 Tecnologias utilizadas:
    • Python, Pandas, NumPy e Matplotlib 🐍
    • Scikit-learn (regressão, árvores, Random Forest, SVM, redes neurais) 🌲
    • MLflow para versionamento de modelos e métricas 📊
    • Docker & Docker Compose 🐳
    • PostgreSQL e MinIO para armazenamento de dados e artefatos 💾
🏆 Principais resultados:
    • Random Forest e Rede Neural capturaram melhor a variabilidade de preços 🌟
    • O atributo “ano do modelo” responde por ~50% da importância no Random Forest 📅
    • Testes estatísticos (Friedman + Nemenyi) confirmaram que Random Forest e Rede Neural têm desempenho equivalente e superior às regressões lineares ⚖️
    • Regressão SVR (SVC) teve o pior desempenho 🤦
    • Modelo final containerizado, com API pronta para previsões em tempo real 🚀
